# HTML TOOLS

A collection of browser-based HTML utilities for everyday document tasks. Each tool is a standalone HTML file and can be opened directly in a modern web browser.

## Getting started

1. Download or clone this project.
2. Open the HTML file for the tool you want to use in a modern web browser.
3. Follow the instructions shown in the tool.

Challan Studio and PDF Merge Studio load their document-processing libraries from a CDN, so an internet connection is needed for those tools to work fully. Resume Studio can be opened directly in the browser.
